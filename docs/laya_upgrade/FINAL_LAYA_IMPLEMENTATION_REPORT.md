## 2. Dataset Program Specification

### Physical Parameter Modeling & Determinism
Dataset generation utilized `training_data/state_generator.py` and `training_data/scenario_generator.py`. Each physical state deterministically simulates:
- **Kinematics**: Position (latitude, longitude), velocity, acceleration, heading ($0^\circ-360^\circ$).
- **Environment**: Terrain friction coefficient, weather precipitation rate ($0-60\text{ mm/h}$), wind vector ($0-45\text{ m/s}$), visibility ($0.5-20\text{ km}$).
- **Communications**: Distance to relay tower, RF path loss, jamming intensity ($0.0-1.0$), packet loss ($0-100\%$), SNR (dBm).
- **Energy & Logistics**: Fuel level ($0-100\%$), battery reserve ($0-100\%$), mechanical wear ($0-100\%$), payload mass ($150-450\text{ kg}$).
- **Mission Progress**: Waypoint progress ($0-100\%$), mission deadline ticks, estimated arrival ticks.

### Splits & Distribution
- **Total Synthesized States**: **100,000**
- **Train Split**: 80,042 samples (80.0%)
- **Validation Split**: 9,997 samples (10.0%)
- **Test Split**: 9,961 samples (10.0%)
- **Soft Label Distribution**: Generated by running 100 prospective future rollouts per state using Monte Carlo environmental perturbations:
  - $\text{Probability}(\text{SUCCESS}) + \text{Probability}(\text{DELAYED}) + \text{Probability}(\text{ABORTED}) + \text{Probability}(\text{FAILED}) = 1.0$

## 3. Neural Architecture & Upstream Laya Research Alignment

Based on research into upstream `NandhaKishorM/laya`:
1. **Non-Autoregressive Feed-Forward Decision Head**: Evaluates operational decisions in a single sub-millisecond forward pass, avoiding autoregressive text latency.
2. **Multi-Task Scoring Heads**:
   - `operational_state` (4 classes: `NORMAL`, `DEGRADED`, `CRITICAL`, `FAILED`)
   - `mission_outcome` (4 classes: `SUCCESS`, `DELAYED`, `ABORTED`, `FAILED`)
   - `logistics_state` (4 classes: `HEALTHY`, `LOW_RESERVE`, `RESUPPLY_REQUIRED`, `CRITICAL`)
   - `communication_state` (4 classes: `CONNECTED`, `DEGRADED`, `INTERMITTENT`, `LOST`)
   - `recommended_action` (5 classes: `CONTINUE`, `REROUTE`, `RESUPPLY`, `PAUSE`, `ABORT`)
   - `risk_score` (Continuous sigmoid regression $[0.0, 1.0]$)
3. **Loss Function**: Combined authoritative cross-entropy and soft distribution alignment (Kullback-Leibler divergence with 100-branch rollouts) plus MSE on risk:
   $$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}} + 0.5 \cdot \mathcal{L}_{\text{Soft\_KL}} + \mathcal{L}_{\text{MSE}}$$
4. **Selective Abstention**: When confidence $\bar{C} = \frac{1}{3}(C_{\text{op}} + C_{\text{outcome}} + C_{\text{action}}) < \tau$ (default $\tau = 0.65$), the model yields `UNCERTAIN` and triggers `RULE_ENGINE_FALLBACK`.

## 5. Temperature Calibration & Reliability Diagrams

Expected Calibration Error (ECE) was calculated across 10 reliability bins according to:
$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$

- **`laya_doip_v1` Calibration**:
  - Before calibration ($T=1.000$): $\text{ECE} = 0.1508$, Brier Score $= 0.1598$

- **`laya_doip_v2` Calibration**:

## 6. Model Disagreement & Active Learning Mining

### Disagreement Engine Architecture (`backend/app/simulation/disagreement_engine.py`)
Compares empirical physics risk equations, authoritative rule boundaries, and calibrated Laya predictions:
- **Nominal State**: All three subsystems agree $\to$ Consensus established, no disagreement recorded.
- **Edge Conditions**: Divergence is categorized by severity:
  - `MINOR`: Soft probability differences $< 0.20$ with matching classifications.
  - `MODERATE`: Risk delta $> 0.35$ or tactical disagreement (e.g. Rules prescribe `PAUSE`, Laya suggests `CONTINUE`).
  - `SEVERE`: Catastrophic conflict (e.g. Rules assert `FAILED` due to 0% fuel invariant, Laya predicts `NORMAL` or `DEGRADED`).

### Active Learning Loop (`backend/app/simulation/active_learning.py`)
1. **Mining Criteria**: Samples with confidence $< 0.70$, operational state mismatches, or high triad risk variance.
2. **Harvested Samples**: Exactly **2,498 hard adversarial samples** mined and persisted to `data/hard_examples/hard_examples.json`.
3. **Fine-Tuning (`harvest_and_train_v2.py`)**: Merged 2,498 hard cases with 80,042 train samples $\to$ yielded `laya_doip_v2` with lower calibrated ECE ($0.0075$) and enhanced critical state robustness.

## 8. Golden Run Determinism & Invariant Protection

To ensure safety-critical integrity, the architecture enforces:
$$\text{World State} \to \text{Physics} \to \text{Rules} \to \text{Feature Extraction} \to \text{Laya} \to \text{Decision Classification} \to \text{Rule Validation} \to \text{State Transition}$$

1. **Rule Invariant Overrides**: If Laya suggests an impossible tactical action (e.g. `CONTINUE` when fuel is $0.0\%$), the `StateTransitionValidator` intercepts the action:
   - `decision_source` $\to$ `RULE_ENGINE_OVERRIDE`
   - `action_accepted` $\to$ `False`
   - `final_action` $\to$ `ABORT` or `RESUPPLY`
   - **Rule Violations**: **0 (Zero)**.
2. **Deterministic Golden Run Protection**:
   - `tests/test_golden_run.py` executed against baseline simulation hashes.
   - Result: **0.000000 drift** (100% byte-identical reproduction). Deterministic simulator runs untouched in `DETERMINISTIC_SIM` mode.
